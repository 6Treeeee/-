## Minimal borrowed design

- From A2A: a stateful task with immutable identity, explicit status transitions, history, and evidence artifacts. The local API remains intentionally project-specific.
- From Codex automation: least-privilege execution, machine-readable events and final schema, resumable identity, and reported token usage.
- From Vercel Workflow: durable idempotent transitions, suspendable task inboxes,
  and append-only state/evidence streams, without importing a general agent
  framework or purchasing another control-plane service.
- From self-hosted runner guidance: keep the executor on an outbound-only trusted machine and separate code-generation credentials from write/promotion authority.

This selection directly serves the first version: fewer moving parts, observable control decisions, bounded repeated attempts, and a replaceable executor interface.
